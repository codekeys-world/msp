1. Introduction

Bienvenue dans le manuel d'utilisation du système de gestion de la Mutuelle du Personnel de la Sécurité Pénitentiaire (MSP). En tant que Secrétaire Organisation, votre rôle est en cours de configuration dans le système.

📋 Autorisations : Les autorisations de ce rôle sont en cours de définition par l'administrateur du système. Contactez l'administrateur pour connaître vos droits d'accès actuels.

2. Connexion au système

2.1 Première connexion

  1. Ouvrez votre navigateur et accédez à l'adresse de l'application.
  2. Entrez votre matricule et votre mot de passe.
  3. Cliquez sur le bouton Se connecter.
💡 Conseil : Changez votre mot de passe après votre première connexion via « Mon profil ».

2.2 Mot de passe oublié

  1. Sur la page de connexion, cliquez sur Mot de passe oublié ?.
  2. Entrez votre adresse e-mail enregistrée.
  3. Vous recevrez un e-mail avec un lien de réinitialisation.

3. Tableau de bord

Le tableau de bord affiche les informations accessibles selon vos autorisations actuelles. Les modules disponibles seront ajoutés progressivement.

4. Mon profil

Depuis Mon profil :

  • Consulter et modifier vos informations personnelles.
  • Changer votre mot de passe.
  • Modifier votre photo de profil.
