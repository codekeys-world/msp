1. Introduction

Bienvenue dans le manuel d'utilisation du système de gestion de la Mutuelle du Personnel de la Sécurité Pénitentiaire (MSP). En tant qu'Administrateur, vous disposez d'un accès complet à toutes les fonctionnalités du système.

Ce manuel vous guide pas à pas à travers chaque module et fonctionnalité disponible.

2. Connexion au système

2.1 Première connexion

  1. Ouvrez votre navigateur et accédez à l'adresse de l'application.
  2. Entrez votre matricule et votre mot de passe.
  3. Cliquez sur le bouton Se connecter.
💡 Conseil : Il est recommandé de changer votre mot de passe après votre première connexion via la section « Mon profil ».

2.2 Mot de passe oublié

  1. Sur la page de connexion, cliquez sur Mot de passe oublié ?.
  2. Entrez votre adresse e-mail enregistrée.
  3. Vous recevrez un e-mail avec un lien pour réinitialiser votre mot de passe.

3. Tableau de bord

Le tableau de bord est votre page d'accueil après la connexion. Il affiche :

  • Vue d'ensemble : Nombre d'adhérents, missions, procès-verbaux, courriers et plaintes.
  • Suivi des missions : État de validation et avancement des ordres de mission.
  • Statistiques des adhérents : Répartition par genre et taux de féminisation.
  • Suivi des courriers : Taux de traitement des courriers.
  • Suivi des plaintes : Taux de traitement des plaintes.
  • Actions rapides : Raccourcis vers les modules les plus utilisés.

4. Gestion des adhérents

Le module Adhérents permet de gérer les membres de la mutuelle.

4.1 Lister les adhérents

Accédez à Adhérents → Liste pour voir tous les membres enregistrés. Vous pouvez filtrer et rechercher par nom, matricule ou téléphone.

4.2 Créer un nouvel adhérent

  1. Cliquez sur + Nouvel adhérent.
  2. Remplissez le formulaire avec les informations personnelles (nom, prénom, date de naissance, etc.).
  3. Ajoutez les informations familiales (conjoint, enfants) si nécessaire.
  4. Uploadez une photo de profil.
  5. Cliquez sur Enregistrer.

4.3 Consulter un adhérent

Cliquez sur le nom d'un adhérent pour voir son dossier complet : informations personnelles, famille, historique, etc.

4.4 Modifier un adhérent

Depuis la fiche d'un adhérent, cliquez sur Modifier pour mettre à jour ses informations.

4.5 Confectionner une carte membre

Depuis la fiche d'un adhérent, cliquez sur Confectionner la carte pour générer la carte membre officielle.

5. Ordres de mission

Le module Ordres de mission permet de gérer les déplacements officiels du personnel.

5.1 Créer un ordre de mission

  1. Accédez à Missions → + Nouvel ordre.
  2. Remplissez les informations : bénéficiaire, destination, date de départ, date de retour, motif.
  3. Uploadez les documents justificatifs si nécessaire.
  4. Enregistrez l'ordre de mission.

5.2 Valider un ordre de mission

Les ordres de mission en attente de validation peuvent être validés depuis la liste en cliquant sur Valider.

5.3 Modifier et rechercher

Vous pouvez modifier les ordres de mission et les rechercher par numéro, bénéficiaire ou date.

6. Procès-verbaux

Le module Procès-verbaux permet de gérer les documents officiels des réunions.

6.1 Créer un procès-verbal

  1. Accédez à Procès-verbaux → + Nouveau PV.
  2. Remplissez : numéro, objet, type de réunion, date, observation.
  3. Uploadez le document PDF du PV.
  4. Enregistrez.

6.2 Lister et consulter

La liste des PV affiche tous les procès-verbaux enregistrés. Cliquez sur un PV pour le consulter en détail.

7. Courriers

Le module Courriers permet de gérer les courriers entrants et sortants.

7.1 Enregistrer un courrier

  1. Accédez à Courriers → + Nouveau courrier.
  2. Sélectionnez le type : Arrivée ou Départ.
  3. Remplissez : référence, objet, correspondant, date.
  4. Uploadez le document du courrier.

7.2 Transmettre un courrier

Un courrier peut être transmis à un autre utilisateur pour traitement via le bouton Transmettre.

8. Plaintes

Le module Plaintes permet de gérer les réclamations des adhérents.

8.1 Enregistrer une plainte

  1. Accédez à Plaintes → + Nouvelle plainte.
  2. Remplissez la date et l'observation détaillée.
  3. Enregistrez.

8.2 Suivi des plaintes

La liste des plaintes affiche l'état de traitement de chaque réclamation.

9. Convocations

Le module Convocations permet de gérer les invitations aux réunions et événements.

9.1 Créer une convocation

  1. Accédez à Convocations → + Nouvelle convocation.
  2. Remplissez la description et la date de la convocation.
  3. Enregistrez.

10. Cas sociaux

Le module Cas sociaux permet de gérer les situations sociales des adhérents (maladie, accident, décès, retraite, etc.).

10.1 Types de cas sociaux

  • Maladie : Cas de maladie d'un adhérent.
  • Accident de circulation : Accident subi par un adhérent.
  • Radiation/Revocation/Retraite/Disciplinaire : Changement de statut professionnel.
  • Décès : Décès d'un adhérent.
  • Réforme/Invalidité : Situation de handicap.
  • Décès d'adhérent : Gestion des droits des ayants droit.
  • Retraite : Départ à la retraite.

11. Prestations

Le module Prestations permet de gérer les aides financières accordées aux adhérents.

11.1 Types de prestations

  • Aide médicale
  • Aide funéraire
  • Aide à la naissance
  • Aide scolaire
  • Autres aides sociales

12. Archives

Le module Archives permet de stocker et consulter les documents archivés.

12.1 Archiver un document

Un document peut être archivé depuis son module d'origine. Les archives sont consultables via Archives → Liste.

13. Gestion financière

13.1 Encaissements

Le module Encaissements permet d'enregistrer les recettes (cotisations, dons, etc.).

13.2 Dépenses

Le module Dépenses permet d'engager et suivre les dépenses de la mutuelle.

13.3 Achat et Vente de matériel

Les modules Achat et Vente permettent de gérer les transactions de matériel.

14. Gestion du matériel

Le module Matériel permet de suivre le parc matériel de la mutuelle : état, localisation, affectation.

15. Administration

🔒 Cette section est réservée aux rôles Administrateur et Super Administrateur (SYSADMIN).

15.1 Gestion des utilisateurs

Depuis Administration → Utilisateurs, vous pouvez :

  • Lister tous les utilisateurs du système.
  • Activer/Désactiver les comptes des utilisateurs via le bouton toggle.
  • Consulter les informations de chaque utilisateur (rôle, email, téléphone, statut).
⚠️ Attention : La désactivation d'un compte empêche l'utilisateur de se connecter. Un message « Votre compte a été désactivé » s'affichera à sa prochaine tentative de connexion.

16. Mon profil

Depuis Mon profil (menu en haut à droite), vous pouvez :

  • Consulter vos informations personnelles.
  • Modifier vos coordonnées (téléphone, email).
  • Changer votre mot de passe.
  • Modifier votre photo de profil.
